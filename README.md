## 🚀 Featured Projects

A selection of projects I've worked on, covering web applications, management systems, and software development.

### 📚 BookPoint

**Book Marketplace Platform**

A book marketplace application designed with separate dashboards and functionality for different user roles.

- Multi-role authentication: Admin, Seller, and Customer.
- Admin management for sellers, customers, and categories.
- Seller dashboard for managing products and transactions.
- Customer purchasing and seller communication features.
- Built with Laravel, React, and Tailwind CSS.

[![Repository](https://img.shields.io/badge/Repository-BookPoint2-181717?style=flat-square&logo=github)](https://github.com/SatriaFarel/BookPoint2)

### 🚗 ParkirKu

**Parking Management System**

A web-based parking management application with membership and parking fee management.

- Parking membership management.
- Free parking access for active members.
- Automatic parking fee calculation for non-members.
- Admin dashboard and parking reports.
- Built with Laravel and Tailwind CSS.

[![Repository](https://img.shields.io/badge/Repository-ParkirKu-181717?style=flat-square&logo=github)](https://github.com/SatriaFarel/ParkirKu)

### 🏘️ SIWarga

**Community Management System**

A web application designed to support neighborhood administration and resident management.

- Resident data management.
- Community administration.
- Monthly contribution management.
- Role-based access management.
- Built with Laravel, MySQL, and Tailwind CSS.

[![Repository](https://img.shields.io/badge/Repository-SIWarga-181717?style=flat-square&logo=github)](https://github.com/SatriaFarel/SIWarga)

### 📖 Buku Tamu Digital

**Digital Guestbook & QR Check-in**

A digital guestbook application for managing visitor records and event invitations.

- General visitor registration.
- QR Code-based invitations for special guests.
- Visitor check-in management.
- Admin dashboard for visitor records.

[![Repository](https://img.shields.io/badge/Repository-Buku--Tamu-181717?style=flat-square&logo=github)](https://github.com/SatriaFarel/Buku-Tamu)

### 📜 Sertificate Kita

**Digital Certificate Management**

A web-based certificate management platform.

- Participant data management.
- Certificate generation.
- PDF certificate downloads.
- Event and participant administration.

[![Repository](https://img.shields.io/badge/Repository-Sertificate--Kita-181717?style=flat-square&logo=github)](https://github.com/SatriaFarel/Sertificate-Kita)
